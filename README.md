# Pocpet-Mint

**Mint 独立版已与 PocPet 原版合并，此后不再更新。** 原版已内置 Mint 角色，请前往 [PocPet GitHub Pages](https://t-meow.github.io/PocPet/) 继续游玩并获取后续更新。

迁移时，先在 Mint「设置 → 存档」导出并保存存档文件，再到原版「设置 → 存档」导入。自定义 Mod 需另行导入对应 zip；确认迁移成功前保留本版数据和备份。两版存档不会自动同步。

## 玩法

- 照顾宠物的饱腹、清洁、心情、体力与健康，获取经验、小心心并提升等级。
- 在商店购买食物、礼物和护理用品，也可以批量使用背包中的普通道具。
- 使用番茄钟完成专注与休息循环，推进每日愿望、回归任务和离线事件。
- 经营花园，解锁地块、种树、浇水、施肥和升级工具，收获道具、金币与金苹果。
- 安排伙伴日程，培养技能、结识 Mod 邻居并领取每日奖励。
- 使用金币或扭蛋券参与金苹果扭蛋，收集增益卡、成就、奖杯并完成伙伴梦想。
- 生日、相遇纪念日、节日和月初会提供日期奖励，错过后可在限定时间内补领。
- 支持 Mod v1/v2、自定义安全道具，以及存档导入、导出、备份和损坏恢复。

## 改动

- 将内置宠物替换为 mint，并调整默认名字、生日、文案、图片和应用图标。
- 使用独立的应用标识、Android 包名、存档、Mod 数据库和发布产物名称，可与原版并存。
- 最终版 `1.3.0` 同步 PocPet `1.8.0` 的厨房、一起游戏、主页改版及存档备份更新，继续兼容旧 Mint 存档与 Mod。
- 按本地日期每天弹出一次合并与停更公告，提供原版 GitHub Pages 和存档导出入口。
